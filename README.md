A small library web app built for the KEA software quality exam project. Users sign up, search books from [Open Library](https://openlibrary.org), then borrow, renew, return and reserve them.

## Features

- Sign up, log in and log out (BCrypt passwords, session cookie)
- Search books through the Open Library API
- Borrow, renew and return books
- Reserve books that are on loan
- Late fees and loan limits (business rules BR-01 to BR-11)

## Tech stack

| Area | Choice |
|---|---|
| Backend | Java 21, Spring Boot 3 (Web MVC, Data JPA, Validation) |
| Database | PostgreSQL 16, schema generated by Hibernate |
| Frontend | Static HTML + vanilla JS, served by nginx |
| External API | Open Library search API |
| Build | Maven |
| CI / quality | GitHub Actions, JaCoCo, SonarCloud |
| Run | Docker Compose |

## Architecture

```
browser -> nginx -> controller -> service -> repository -> PostgreSQL
                                    |
                                    +-> OpenLibraryClient -> Open Library
```

## Getting started

Requires Docker, or Java 21 and Maven for local development.

## Build and test

```bash
cd backend
mvn package -DskipTests   # build
mvn verify                # run tests with JaCoCo coverage
```

## ON CASCADE ACTIVATION

docker compose down -v
docker compose up -d --build


## API

| Method | Path | Description |
|---|---|---|
| POST | `/api/auth/signup` | Create an account |
| POST | `/api/auth/login` | Log in |
| POST | `/api/auth/logout` | Log out |
| GET | `/api/auth/me` | Current user and amount owed |
| GET | `/api/books?q=` | Search books |
| GET | `/api/books/{workId}` | Book details and availability |
| GET | `/api/loans` | My loans |
| POST | `/api/loans` | Borrow a book |
| POST | `/api/loans/{id}/renew` | Renew a loan |
| POST | `/api/loans/{id}/return` | Return a loan |
| POST | `/api/reservations` | Reserve a book |
| DELETE | `/api/reservations/{id}` | Cancel a reservation |
